# CBPIR

**Content-Based Private Information Retrieval over Structured Databases via Homomorphic Encryption**

CBPIR was accepted at NSS–SocialSec 2026. This repository is the landing page for the project.

## Implementation and evaluation

**[Visit the CBPIR implementation repository](https://github.com/mteng39/cbpir-socialsec26)**
